# FIIO Air Link Control

[English](README.md) | Русский

FIIO Air Link Control (FALC) — неофициальное open-source приложение для
управления FIIO Air Link в Windows через USB. Оно позволяет настраивать кодеки,
управлять Bluetooth-устройствами, выполнять сопряжение и собирать диагностику без
официального приложения производителя.

Приложение работает локально и не использует телеметрию, рекламу, учётные записи
или облачные сервисы.

## Интерфейс

### Обзор

Показывает основное состояние Air Link:

- прошивку устройства и версию приложения;
- активное Bluetooth-подключение и количество подключённых гарнитур;
- включённые кодеки и режимы LDAC/aptX Adaptive;
- Bluetooth-имя и яркость индикатора, полученные от устройства.

На этой вкладке можно обновить состояние или отключить текущую USB-сессию.
Автоматическое подключение возобновится после запуска новой сессии.

### Аудио

Управляет возможностями Bluetooth-аудио:

- включает и выключает поддерживаемые кодеки;
- выбирает режим качества LDAC;
- выбирает режим качества aptX Adaptive.

После каждого изменения приложение повторно читает состояние Air Link и только
затем сообщает об успехе. Фактически используемый кодек также зависит от
подключённого приёмника и условий радиосвязи.

### Устройства

Управляет Bluetooth-приёмниками и наушниками:

- показывает сопряжённые устройства и состояние их подключения;
- подключает или отключает ранее сопряжённое устройство;
- запускает поиск новых устройств на 60 секунд;
- позволяет выбрать и сопрячь найденное устройство.

Air Link должен быть подключён по USB. Перед поиском включите режим сопряжения на
целевом устройстве и отключите его от других Bluetooth-источников.

### Диагностика

Показывает информацию для поиска проблем:

- прошивку и параметры HID-интерфейса;
- успешные запросы, тайм-ауты и ошибки ввода-вывода;
- счётчики отключений и переподключений;
- версию приложения и исходный commit;
- экспорт диагностического JSON с защитой данных.

Журнал сырых пакетов по умолчанию отключён. При экспорте содержимое пакетов и
идентификаторы устройств скрываются.

## Требования

- 64-разрядная Windows 10 или Windows 11;
- Microsoft Edge WebView2 Runtime, обычно уже установленный в Windows;
- FIIO Air Link, подключённый через USB;
- аппаратно проверенная прошивка: `1.4.0`.

## Скачать

Скачайте актуальные `FIIO-Air-Link-Control.exe` и `.sha256` со страницы
[GitHub Releases](https://github.com/denzharkov/fiio-air-link-control/releases).
Установка и Python не требуются.

EXE пока не подписан, поэтому при первом запуске Microsoft SmartScreen может
показать предупреждение.

## Язык

По умолчанию интерфейс запускается на английском. Переключиться на русский можно
через список языков в верхней панели. Выбор сохраняется локально для следующего
запуска.

## Разработка

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m fiiocontrol
```

Сборка portable EXE:

```powershell
.\.venv\Scripts\python.exe scripts\build_windows.py
```
